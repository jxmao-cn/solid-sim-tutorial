# 组会报告生成

生成一份固定格式的中英双语组会汇报材料，作为学习凭证交付给导师。严格执行以下流程，**不要跳过任何一步**。

## 1. 确定报告期

- 读 `reports/index.md`（报告索引）与 `PROGRESS.md`（学习日志），取两者中最新的日期作为报告期起点 `<since>`；终点为今天。
- 若用户提供了 `$ARGUMENTS`（YYYY-MM-DD），以用户为准。
- 先用一句话向用户明示报告期（如"本期报告覆盖 2026-08-06 → 2026-08-07"）。

## 2. 收集证据（静态为主）

1. 运行证据收集器：
   `python3 tools/changes_since.py <since>`（仓库根下运行；工具脚本仅标准库，任何机器上的 python3 均可）
   （输出 git 提交、变更文件、gif/obj 证据、PROGRESS.md 条目）
2. 对**最近改动的 pygame 章节**（0–8 章）最多跑一次无头截图（可选、限时）：
   `python3 tools/headless_capture.py <最近改动的章节主脚本> --timeout 30`
   - 截图输出在章节 `output/capture/`（已 gitignore）。
   - **10–14 章（taichi/warp）绝不自动运行**，证据用仓库已有 `results.gif` + readme。
3. 读取 PROGRESS.md 中报告期内的条目；读取相关章节的 readme 与代码中的中文学习注释（如 `0_getting_started/newton.py`）。

## 3. 与用户确认（恰好两个问题，纯文本提问）

1. 报告期是否正确？（可给新的起止日期）
2. 本期平板公式笔记是否已整理？若有，给出文件路径（将嵌入第 4 节）；否则写占位说明。

## 4. 生成报告

输出到 `reports/组会报告_<YYYY-MM-DD>.md`（日期为报告期终点），按以下**固定模板**（中英双语：每节中文正文 + 末尾一段英文 summary）：

```markdown
# 学习进度组会报告 (<日期>) — Solid-Sim Study Progress Report
报告期 / Period: <since> → <to> | git HEAD: <hash> | Repo: solid-sim-tutorial

## 1. 学习内容与阅读进度 / Reading Progress
表格: 仓库章节 | 对应 phys-sim-book 章节(链接) | 状态(通读/复现/待加深) | Elastogen 相关性
(教材映射表见 CLAUDE.md；phys-sim-book 本机路径随机器而异：Linux 原机为 /home/steven/mjx/phys-sim-book/src/，本 Mac 机器另行确认)

## 2. 代码实现与复现 / Code & Reproduction
每条: 文件链接(相对路径) | commit hash | demo 演示内容 | 中文注释/推导所在位置

## 3. 验证与效果 / Verification
证据: gif 嵌入或链接(相对路径，如 ../9_reduced_DOF/results.gif)、无头截图、output/*.obj 帧数统计、运行观察
(10–14 章注明证据来源为上游 results.gif)

## 4. 公式推导笔记 / Formula Notes
本期若未接入平板笔记: 写占位说明(约定 formula-<date>.pdf 放 reports/formula/，后续版本自动嵌入)
若用户给了路径: 以链接/图片嵌入此处

## 5. 遇到的问题与解决 / Problems & Solutions
取自 PROGRESS.md 条目: 问题 → 解决 → 遗留

## 6. 下一步计划 / Next Steps
本期 PROGRESS.md 的"下一步" + 长期路线(如: 后向欧拉子模块 → 多维仿真 → 9 章模态降维 → Elastogen AEtest 对照)

## 7. 对 Elastogen 复现的支撑 / Relevance to Elastogen
显式映射表: 本期学习内容 → Elastogen 方法(用 CLAUDE.md 映射表; 如 投影牛顿/增量势 ↔ PDNet 局部-全局迭代)
```

约束：
- 中文正文 + 每节英文 summary；gif/图片用**相对路径**（报告在 reports/，仓库根为上一级）。
- **绝不修改 PROGRESS.md**（它是 hook 自动维护的真源）。
- 报告中每条证据给出可验证位置（文件:行号、commit hash、命令）。

## 5. 更新索引

在 `reports/index.md` 表格末尾追加一行：`| <日期> | 组会报告_<日期>.md | <since> → <to> | <一句摘要> |`

## 6. 收尾

输出一行完成提示（含报告文件路径），并简述报告期与主要内容。不要做其他事情。
